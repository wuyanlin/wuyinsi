桐宝清单 · 隐私政策

Tongbao Checklist · Privacy Policy

不收集任何个人数据 · 无广告 · 无追踪

生效日期：2026 年 10 月 13 日　|　适用版本：1.0.0 及以上

「桐宝清单」（以下简称「本App」）是一款用于记录个人物品与家庭记账的离线工具。本App 的设计原则是「数据归你所有」——我们不会收集、上传、共享或出售你的任何个人信息。

一句话总结：你录入的物品、照片、账目、备注全部保存在你自己的设备、你自己的 NAS 或你自己的 iCloud 账户里。我们（开发者）无法看到、也无法访问这些数据。

一、我们收集哪些信息

我们不收集任何个人信息。具体而言，本App 不收集、不上传、不与任何第三方共享：

信息类别是否收集说明
姓名、邮箱、手机号等身份信息不收集本App 没有注册/登录流程，不需要你提供任何身份信息
物品名称、照片、购入价格、备注不收集仅存储于你的设备 / 你的 NAS / 你的 iCloud，不经过开发者
账目金额、分类、商户、备注不收集同上
精确或粗略位置不收集App 不使用定位信息
通讯录、短信、通话记录不收集App 不访问这些系统数据
使用行为 / 崩溃 / 性能数据不收集没有埋点、没有分析 SDK、没有崩溃上报
广告标识符（IDFA）不收集App 内无广告，不做任何追踪

二、数据保存在哪里

为了让你的数据「离开开发者也能安全保存」，本App 支持三种存储方式，全部由你选择和掌控：

1. 本机存储（默认）

数据以本地数据库形式保存在你的 iPhone / iPad 上。卸载App 即彻底删除，不留任何副本。

2. 你自己的 NAS（可选）

如果你在家庭局域网中运行了本App 的配套服务端（youshu），App 可以通过局域网把数据同步到你自己拥有的 NAS 设备上。传输过程在你的家庭网络内部完成，数据不会经过任何第三方服务器或云服务，开发者也无法访问。

3. 你自己的 iCloud（可选）

你可以在设置中开启「iCloud 自动备份」，备份文件会写入你自己 Apple 账户下的私有 iCloud 云盘（Documents 容器）。该数据受Apple 的 iCloud 隐私机制保护，仅你可见，开发者的开发者账号无法访问。

这三种方式互不冲突。你也可以随时关闭同步、删除 App、或在「备份与恢复」中导出 / 导入 CSV、JSON 文件，数据完全由你掌控。

三、系统权限说明

本App 会在你主动触发相关功能时请求以下系统权限，且不会在未授权时影响核心功能：

权限用途触发时机
本地网络 发现并访问你家庭局域网内的 NAS，实现数据同步 你在「我的 → NAS 连接」中填写服务器地址后
照片 / 相册 为物品选择一张封面照片 你在「图标选择 → 相册」中主动选择照片时
Face ID / Touch ID 启用应用锁后，通过生物识别解锁你的数据 你在「我的 → 应用锁」中开启后
文件系统（文档） 导入 / 导出 CSV、JSON 备份文件；读写 iCloud 备份目录 你在「备份与恢复」中操作时

你可以随时在 iOS 的「设置 → 桐宝清单」中撤销上述任何一项授权。撤销后对应功能不可用，其余功能不受影响。

四、共享扩展与屏幕识别

本App 提供两项完全在本机完成的辅助功能：

  • 分享扩展：你可以从其他App 把一张收据截图分享到「桐宝清单」，App 会在设备本地通过系统 OCR 识别金额与日期并生成一条待确认的记账草稿。图片与识别过程不会离开你的设备。
  • 截图 / 图片识别记账：同样使用设备本地的 Apple Vision 框架完成识别，识别结果仅写入本机数据库。

我们不会因为你使用了这些功能而收到任何图片或识别内容。

五、第三方服务

本App 不集成任何第三方分析、广告、崩溃统计或社交 SDK。App 内出现的以下服务均由Apple 系统提供，不受本开发者控制，其行为适用 Apple 自身的隐私政策：

  • iCloud（可选备份）
  • Face ID / Touch ID（可选应用锁）
  • 系统 OCR 文字识别（Vision 框架）
  • App Store 及其支付与下载服务

六、小童与家庭使用

本App 是面向家庭资产与日常记账的通用工具，不会主动收集任何儿童个人信息。本App 的年龄分级为 4+。如果你认为儿童在未经监护人同意的情况下向我们提供了个人信息，请通过下方邮箱联系我们，我们会尽快处理。

七、数据安全

  • 本机数据存储在 iOS 系统的沙盒环境中，受系统级隔离保护。
  • 可选的应用锁会对数据加一层面容 ID / 触控 ID 或密码保护（密码以 SHA256 加盐哈希形式存储，不保存明文）。
  • 与 NAS 的同步仅在你的家庭局域网内进行；如需公网访问，请自行使用 HTTPS 方案（App 的公网连接要求 https）。
  • iCloud 备份受 Apple 账户的加密与隐私机制保护。
  • 我们建议你启用 iOS 设备锁，并在设备丢失时及时撤销相应授权。

八、你的权利

因为我们不收集数据，所以也不存在「向开发者申请查询 / 更正 / 删除数据」的需要。你的数据控制权完全在你手上：

  • 随时在App 内编辑或删除任意物品、账目、分类
  • 随时导出 CSV / JSON 备份，或从备份恢复
  • 随时关闭 iCloud 自动备份、NAS 自动同步
  • 卸载 App 即删除本机全部数据（iCloud 与 NAS 上的副本需你自行在对应处删除）

九、政策的变更

若本隐私政策发生实质性变更，我们会在App 内或更新说明中向你提示。继续使用本App 即表示你接受更新后的政策。
